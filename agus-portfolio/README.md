# Agus Budi — Developer Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Customize
- Update the name, bio, study details, and project descriptions in `index.html`.
- Replace GitHub profile links with individual repository links when available.
- Adjust colors and layout in `style.css`.

## Deploy with GitHub Pages
1. Push these files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Wait for the published site URL to appear in the Pages section.
